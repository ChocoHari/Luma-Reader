## Tagline

A quieter place to read.

## Short description

Luma is a Windows document reader and Markdown editor with local Piper voices, original-page PDF reading and offline OCR. It is an open-source project in development, built to make reading and note-taking feel more comfortable.

## Project page

Read a document, listen to a passage, and keep your notes close by.

Luma brings PDF, DOCX, TXT, Markdown and HTML reading into a simple Windows workspace. Keep the original PDF page in view, select text to hear it, or write a Markdown note with a live preview. Local Piper speech and OCR let the main reading workflow work offline once the required models are installed.

Choose baby blue, coral, lavender or soft brown in light or dark. Use focus mode when you want fewer controls, and keep important notes saved with local recovery available for unsaved drafts.

Luma is still a development preview. OCR and complex PDF reading order need checking, and some Windows configurations remain untested. The community source is licensed under AGPL-3.0-or-later; third-party components and voices retain their own terms.
