# Announcement drafts

## Development update — usable while release checks are open

I'm building Luma, a Windows reader and Markdown editor with an offline core.

The latest development work brings original-page PDF selection, local Piper speech, OCR for scanned text and a Markdown workspace with source, preview and split views. Light and dark themes help make it a comfortable place to read and write.

It is still a preview: complex PDF reading order, OCR mistakes and Windows compatibility checks need more work. I'm preparing the open-source release carefully and sharing progress as the checks are completed.

I'm developing Luma alongside university studies. If you would like to help, feedback on original sample documents and code contributions will be valuable. Optional financial support will be available only once a suitable payout route is confirmed.

## Release announcement — hold until release gates pass

Luma Reader is ready for its first public beta: a Windows document reader and Markdown editor with local Piper voices and an offline core.

Keep an original PDF page in view, select a passage to hear it, and write notes with a live Markdown preview. OCR helps recover legible text from scanned pages; check complex layouts and important amounts against the original.

The community source is open under AGPL-3.0-or-later. Please read the beta's supported configuration and known issues before installing.

I'm a university student building this project independently. Testing, contributions and optional support help me continue improving it.
