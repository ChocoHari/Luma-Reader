# Beta test and feedback guide

Use original or public-domain sample documents for shared reports. Keep private books, notes, screenshots, extracted OCR text and full logs out of public issues. Describe the problem with the smallest non-private sample that reproduces it. Local logs and recents can contain filenames and paths; review and redact them before sharing.

## Test sequence

1. Record Windows version, display resolution/scaling, audio device type and Luma source fingerprint. Do not include account names, serial numbers or identifying device names.
2. Launch the portable copy without the development environment. Open PDF, DOCX, TXT, MD and HTML samples. Confirm the expected original-page/text/editor view.
3. Select/copy/read a sentence; pause, resume, stop, change speed and export WAV. Confirm output matches the intended text and no old speech resumes after stop.
4. Try an ordinary, rotated, two-column and scanned PDF. Check zoom, highlight placement, page selection, OCR and cross-page selection.
5. Create a Markdown note; exercise Source/Preview/Split, headings, lists, tasks, links and tables. Save/reopen; recover an unsaved draft; check Cancel and Discard separately.
6. Check light/dark themes, custom and standard frames, maximize/restore, Snap, keyboard navigation, taskbar bounds and available monitor configurations.
7. With a disposable test copy, check installer cancellation, upgrade from a documented previous candidate, uninstall and retained user notes. Do not target a working installation without backing up its data.
8. Repeat the primary reading, writing and speech checks offline. Network should be needed only for deliberate downloads or external links.
